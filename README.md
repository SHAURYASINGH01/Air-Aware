# AirAware — Campus Air Safety

## Overview
AirAware is a campus-focused project concept designed to help students and campus organizers understand air-quality conditions and make informed decisions about outdoor activities.

## Goals
- Present air-quality information in a campus-friendly format.
- Provide practical guidance for activities such as outdoor sports, assemblies, and commuting.
- Make unavailable or estimated data clear to users.

## Project Package
The repository currently contains `AirAware_Final_Project.zip`. Download and extract it to inspect the included project files.

## Technology and Integrations
The project plan has explored a web interface, a Python API, air-quality data sources, and possible AWS/AI integrations. Verify the source code and runtime configuration before treating any integration as active.

## Current Status
This README describes the project goals and repository contents. It does not claim that live AQI data, AWS hosting, Amazon Bedrock, or Strands Agents are deployed and working.
